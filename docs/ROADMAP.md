# Roadmap

## Current focus

- harden the Soroban starter contract patterns
- improve project onboarding and documentation clarity
- provide safer and more transparent deployment guidance
- establish maintainable contributor workflows

## Near-term goals

- add reusable contract examples beyond the hello-world baseline
- improve frontend integration with wallet and contract calls
- add end-to-end validation guidance for testnet workflows
- tighten CI validation and audit checks

## Long-term goals

- provide modular app templates for different Stellar use cases
- support broader real-world deployment patterns
- reduce friction for contributors who want to extend the starter project
